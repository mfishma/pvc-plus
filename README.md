# PVC-Plus Resource Pack

A custom resource pack for Minecraft 1.21.5+ for players on Peaceful Vanilla Club that applies custom textures to PVC-specific items based on their display names and/or enchantments (NBT data).

## What's in the box?

Here's a visual reference of the custom items, categorized by their in-game toggle groups.

## Customization (Optional: Respackopts)

This pack includes built-in support for the **[Respackopts](https://modrinth.com/mod/respackopts)** mod, allowing you to pick and choose which of the categories you want on or off in-game.

### In-game configuration
If you have Respackopts installed:
1. Go to *Options* ➔ *Resource Packs*.
2. Click the settings button next to the PVC+ resource pack.
3. Toggle any of the 
categories on or off

---

## Installation

1. Download the compiled zip folder.
2. Place the zip file in your Minecraft `resourcepacks` folder.
3. Enable the resource pack in Minecraft settings.

## Technical Structure

The pack follows a strict separation between vanilla logic overrides and custom assets designed to support complex custom model mapping:

- **`assets/minecraft/items/*.json`**: Vanilla Item Model Logic that hijacks the original item and checks the name.
- **`assets/pvc-plus/models/item/*.json`**: Custom Item Models that are used by the Vanilla Item Model Logic, usually named for their in-game name.
- **`assets/pvc-plus/textures/item/`**: Project-specific visual texture assets, usually named for what they look like.
